View

Only one gear moves to shift: the 72T slider on the input shaft. It can only mesh one output at a time, so two outputs can never engage together. Shifts run stop motors, slide, spin up. Uses 2 of the kit's 6 HD Hex motors. Layout model in millimetres, not a CAD file.
